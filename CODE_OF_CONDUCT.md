# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and technically constructive community. Contributors must communicate professionally, assume good intent, accept evidence-based feedback, and focus criticism on code and decisions rather than people.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, deliberate disruption, unwanted sexual attention, and publishing private information without consent.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict participation when this code is violated. Report concerns privately through the security contact described in `SECURITY.md` or directly to the maintainers.

Retaliation against a good-faith report is not acceptable.
